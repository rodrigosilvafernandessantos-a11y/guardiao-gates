# Entradas do piloto

Área reservada para futura materialização dos documentos D01–D07 e das vinte variantes normal/maliciosa. Nenhum desses arquivos individuais foi criado nesta organização.

Referência: [documentos do piloto](../../docs/especificacao/documentos-do-piloto.md) e [ataques adaptados](../../docs/avaliacao/ataques-adaptados.md).

As entradas não devem incluir comentários do pesquisador ou respostas esperadas. O documento restrito D07 não pode ser colocado no contexto comum. Registrar UTF-8, versão e hash na futura exportação. As futuras entradas e configurações sintéticas pequenas podem ser versionadas no Git com seus IDs e hashes; não incluir credenciais, dados privados ou saídas de execução.
